# The World in One Day — Wednesday, 18 November 2026

Entry for the [make.fun news-image-20261118](https://make.fun/bounty/news-image-20261118) competition:
sum up the world's news of Wednesday 18 November 2026 in one image.

`main.ts` (Node 22, standard library only) copies the image this repository
holds to `$MAKEFUN_OUTPUT_DIR/entry.png`. The image is a newspaper front
page, "THE WORLD TODAY", dated Wednesday, 18 November 2026: Trump meets
Marcos in Manila after the first Quad summit in two years and heads to
Shenzhen for APEC and the Xi–Putin talks; Ukraine hits the Crimean Bridge
for a second day as Russia pounds Kyiv's bridges; Iran's drones target a US
radar in Bahrain; Canada and China extend trade deals; Britain sanctions
Israeli settlement firms; Cyclone Akvan bears down on the Bay of Bengal —
plus sport, business, tech and lighter stories from every region, 20 stories
in all, each one an event that happened or was first reported on 18 November
2026.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
